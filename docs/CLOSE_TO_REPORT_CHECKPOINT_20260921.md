# Close-to-report checkpoint — 2026-09-21

Financial statements are generated only from an approved, fingerprinted month-end close. The report package contains an evidence-linked trial balance, profit and loss, balance sheet, direct cash-flow summary, retained-earnings movement and prior-period comparison when an earlier approved package exists.

Each trial-balance row retains its approved journal or closing-adjustment references. The package is itself fingerprinted and follows maker-checker approval. PDF and Excel exports remain unavailable until an independent approver accepts the package.

The reporting package is target-ERP evidence. It does not amend BizModo, permanently post a journal, or lock the fiscal period. In controlled staging, the September example therefore reflects only approved target-ERP journal plans and the approved closing accrual—not the complete historical business result that will exist after final data replacement.
